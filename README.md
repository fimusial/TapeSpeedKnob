# Tape Speed Knob
![Tape Speed Knob](/tape-speed-knob.png)
A VST3 plugin to slow audio down with just a single knob.

#### Import?
Simply grab the binary from *Releases* and put it somewhere your DAW can see it. There is only a 64-bit version.

#### Have Fun?
The effect is applied whenever audio is playing and the plugin is not bypassed. So automate the bypass parameter AND **the knob**.

#### Compile it?
Nope. At least not without the VST3 SDK (not included, sorry). If you really feel like trying, follow the tutorials here: https://steinbergmedia.github.io/vst3_dev_portal/pages/index.html
